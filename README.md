# 🌿 Herbarium Arcana

Um herbário digital encantado para descobrir, catalogar e aprender a cuidar de plantas.

## ✨ Aprendendo enquanto construo

Este projeto está sendo desenvolvido por uma estudante de Análise e Desenvolvimento de Sistemas que está aprendendo programação na prática.

O código, as decisões técnicas, os erros e os aprendizados serão documentados para que outros estudantes e iniciantes possam acompanhar e aprender junto.
